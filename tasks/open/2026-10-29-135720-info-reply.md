# Info reply

Accept the `info` reply type (`contract-protocol.md`, Response body).

- The reply check takes `info` as a fifth type. An info has a `text`, a string
  of at most 2000 characters (Unicode code points); every other reply text stays
  at 200 (`contract-protocol.md`, Limits).
- An info goes through when `MAX_PLANS` is reached, like every reply that is not
  a new plan (`architecture.md`, Requests).
- Tests for each.
