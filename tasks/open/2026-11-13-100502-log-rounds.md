# Log rounds

`LOG_ROUNDS` logs each answered round, as `architecture.md` (Configuration and
the stateless bullet) says.

- When `LOG_ROUNDS` is `true`, every round the server answers with `200` is
  logged to the console as one JSON line, such as
  `{"round": <request body>, "response": <response body>}`. Other values and no
  value turn it off. Rounds answered with an error are not logged.
- At startup, with it on, the server logs a warning, as for
  `ALLOW_UNAUTHENTICATED`: that each round's content is logged, for development
  only.
- `README.md`: the setting, next to the others, in simple English, with the same
  warning.

Tests: with it on, a round gives one line that parses as JSON and holds the
request body and the response; with it off, no such line; the startup warning
when it is on.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
