# Log the user with each round

Each line of `LOG_ROUNDS` names the user, as `architecture.md` (Configuration)
says.

- The line is
  `{"user": <sub>, "round": <request body>, "response": <response body>}`, with
  `user` first.
- `user` is the `sub` of the verified token. It is `null` when the token has no
  `sub` or when `ALLOW_UNAUTHENTICATED` is on.

Tests: a token with a `sub` gives that `user`; a token without one gives `null`;
with tokens not checked, `null`.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
