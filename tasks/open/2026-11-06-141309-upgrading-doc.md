# Upgrading doc

Give the people who run dicta-action-server a guide to upgrading a site's dicta,
in simple English (`CLAUDE.md`, User documents), as `contract-protocol.md`
(Versions) describes.

- `docs/upgrading.md`:
  - the three parts that move: the server, `dicta-action-js` and the site's
    module, and that the release notes say what changed;
  - until `1.0.0`: any release may break; update the three together, after
    checking the module with the updated harness;
  - from `1.0.0` on: the server first, then the module and `dicta-action-js`; a
    new protocol version runs next to the old one for a while;
  - updating the server itself: get the new code, `npm install`, restart. It
    keeps no data, so nothing is moved.
- `README.md` links to it.
