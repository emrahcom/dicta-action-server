# Type lists

Accept a list of types in capability schemas, as `specs/contract-capability.md`
(Capabilities) and `specs/contract-context.md` (Checks) describe.

- The context check in `src/context.ts` takes a `type` that is one of the seven
  types or a non-empty list of them without repeats, and refuses anything else
  with an error that names the field. `args` keeps the single type `object`.
- The plan check in `src/plan.ts` lets a value pass a type list when it matches
  any type in it. The error names all the types, such as
  `steps[0].args.due must be of type string or null`.
- Tests for: a list in `args` and in `output`; an empty list, a repeat and an
  unknown type in a list, refused; a plan argument that matches the first type,
  the second type, and neither; `null` in an argument whose type is only
  `string`, still refused.
