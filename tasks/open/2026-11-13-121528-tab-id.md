# Tab id

`tabId` is a required field of the request body (`contract-protocol.md`, Request
body), and each line of `LOG_ROUNDS` names it (`architecture.md`,
Configuration).

- A body without `tabId`, or with one that is not a string, fails the round
  check with `400` naming the field, as for `requestId`.
- The planner does not get it: the claude planner's prompt stays the same.
- The log line is `{"user": ..., "tabId": ..., "round": ..., "response": ...}`,
  with the body's `tabId` second. `round` stays the body as sent, with its
  `tabId`.

Tests: the test bodies send a `tabId`; a body without one and a body with a
number get `400` naming the field; the log line holds the `tabId` after `user`.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
