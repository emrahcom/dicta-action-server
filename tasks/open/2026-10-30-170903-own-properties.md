# Own properties

A plan's `args` have every required property and no property the schema does not
name (`contract-plan.md`, Failures). The plan check reads these with `in`, which
also finds names every JavaScript object inherits, such as `toString`,
`constructor` and `__proto__`.

- The plan check counts only a value's own properties and the names the schema
  itself lists: an argument named `__proto__` or `toString` that the schema does
  not name is refused, and a required property is present only when the value
  has it.
- Tests for `__proto__`, `toString` and a missing required `constructor`.
