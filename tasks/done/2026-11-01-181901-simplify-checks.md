# Simplify checks

Remove duplicated code and a duplicated test. No spec changes; the checks still
follow `contract-plan.md` (Failures) and `contract-context.md`.

- In `src/plan.ts`, a capability without `args` is checked with `matches` and an
  empty schema, `capability.args ?? {}`, instead of its own branch. The error
  for an extra argument becomes the usual "is not in the schema"; the test that
  expects "args must be {}" is changed to match.
- `isObject` is defined once, exported from `src/context.ts`, and imported in
  `src/plan.ts` and `src/round.ts`.
- In `test/plan.test.ts`, one of the two "a call without args" cases is removed.
