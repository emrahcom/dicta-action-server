# JWT audience

Add `JWT_AUDIENCE`, as `architecture.md` (Authentication, Configuration) says:
when it is set, a token whose `aud` is not that value, and is not a list that
holds it, is not valid and the round gets `401`; when it is not set, `aud` is
not checked. The README describes it in simple English, with its use next to
`dicta-server`.

Tests: with `JWT_AUDIENCE` set, a token with that `aud`, and one with a list
that holds it, is accepted; a token with another `aud` or none gets `401`.
Without it, a token with any `aud` or none is accepted.
