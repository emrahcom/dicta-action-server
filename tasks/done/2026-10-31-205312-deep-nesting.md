# Deep nesting

A body nested too deeply to be turned back into JSON is not valid and gets a
`400`, not a `500` (`contract-protocol.md`, Errors).

- The round check refuses such a body with the error "the body is nested too
  deeply", before any other check.
- Test: a body whose `state` is an array nested 20000 deep gets a `400` with
  that error.
