# File structure

Structure fixes from the code quality review of 2026-11-20, with no change in
behaviour: code moves to the file a reader would look for it in, and long
functions get smaller parts.

- `src/plan.ts`: `cutPlanTexts(plan)` cuts the label, the step texts and the
  progress, and drops a `checkpoint` from the planner (`contract-plan.md`,
  Limits and Checkpoint). It moves here from `checkReply`, so the three text
  limits are no longer exported. A `forEach` step is checked by its own
  `checkForEach`, as a call is by `checkCall`.
- `src/reply.ts`, new: the reply check of `round.ts` with `cut`, `BadReply` and
  the reply limits (`contract-protocol.md`, Response body). `round.ts` keeps the
  request body check and `pickReply`.
- `src/round.ts`, `pickReply`: the planner call with its time limit is its own
  `callPlanner`, so `pickReply` reads as the list of rules. `countPlans` and
  `isCheckpoint` hold the plan count and the checkpoint rule, used by
  `pickReply` and by the Claude planner, so the two cannot drift.
- `src/planners/claude.ts`: `request` is named `callParams`, since "request"
  means the user's request elsewhere.

Tests: the existing tests pass, changed only where a name moves.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
