# Names, not ids

Add the rule that texts for the user name things by their titles and names,
never by ids, to the `claude` planner's instructions, as
`specs/architecture-planner.md` (Rules for the LLM) describes.

- The rule in `INSTRUCTIONS` in `src/planners/claude.ts`, after the language
  rule.
- A run of the LLM check in `dicta-action-kit` with the defaults, reported: no
  user text names an id, and no case does worse than before.
