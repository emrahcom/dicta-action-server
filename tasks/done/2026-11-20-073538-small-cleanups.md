# Small cleanups

Code quality fixes from the review of 2026-11-20, with no change in behaviour
and no move between files.

- `src/plan.ts`: one helper for an optional text of at most N code points, used
  for the label, a step's text and the progress. One function counts code
  points, in `plan.ts` and `round.ts`.
- `src/round.ts`: `checkText` and `checkHistoryText` become one function that
  takes the limit. The fixed stop "Something went wrong." is one constant.
  `checkItem` tests for an object once. The halt variable `f` is named `halt`.
  `isLocalTime`, `BadReply`, `PLANNER_MS` and `PlanLimits` move up to the other
  definitions, before their first use.
- `src/planners/claude.ts`: imports `isObject` from `../context.ts` in place of
  its own copy, and drops the cast it needed.
- `src/index.ts`: one helper reads a bounded whole number setting, for
  `MAX_PLANS` and `PLANS_PER_CHECKPOINT`.
- `ClaudeOptions` and `ServerOptions` take the plan limits as one `PlanLimits`;
  `index.ts` builds it once.
- Exports nothing imports lose `export`: `LEVELS`, `Level` and `Capability` in
  `context.ts`; `Report`, `HistoryEntry` and `PlanLimits` in `round.ts` where
  only the file uses them; `readReply` in `claude.ts`; `ServerOptions` in
  `server.ts`. The harness imports only `checkContext` and `src/index.ts`.
- Error messages that write out a limit use its constant.

Tests: the existing tests pass, changed only where a name or a type changes.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
