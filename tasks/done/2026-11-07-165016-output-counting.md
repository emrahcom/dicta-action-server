# Output counting

Count the included outputs of a report as `contract-protocol.md` (Report) says:
each output on its own, as the UTF-8 bytes of its JSON, the sizes added up,
`halt.outputs` included. Today the server counts the whole `outputs` object, so
a report the client kept within 16 KB can get a `400`.

Tests: outputs that add up to exactly 16 KB pass, though their object with its
keys is larger; one byte more is a `400`.
