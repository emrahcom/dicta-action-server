# README

Give dicta-action-server a `README.md` for the people who run it, in simple
English (`CLAUDE.md`, User documents).

- What it is: it turns a user's request into a plan for the browser, with an LLM
  planner. It never acts on the site, and it keeps no data between requests.
- Running it: the Node.js version, `npm install` and `npm start`, and the
  environment variables of `architecture.md` (Configuration), with
  `ALLOW_UNAUTHENTICATED` for development only.
- Tokens (`architecture.md`, Authentication): what the site's backend signs.
  Per-user rate limits belong in that backend, since each request costs planner
  money.
- Network: all paths start with `/dicta-action/`, so it can share a domain
  behind a proxy; Chromium's Local Network Access blocks or asks before a public
  site calls a server on a private address.
- Links to `dicta-action-js`, `dicta-action-harness` and the specs.
