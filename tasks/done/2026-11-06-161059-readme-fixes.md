# README fixes

Two fixes in `README.md`, found in the spec review.

- `JWT_SECRET`: required unless `ALLOW_UNAUTHENTICATED` is `true`, as
  `architecture.md` (Configuration) says.
- Network: a public site's users reach the server through a public address, or
  through the site's own domain behind a proxy. Drop "in the same network as the
  site": the users' browsers, not the site, must reach it.
