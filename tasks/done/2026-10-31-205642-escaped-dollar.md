# Escaped dollar

The plan check compares a string written with `$$` with its schema as the
capability gets it, with a single `$` (`contract-plan.md`, References).

- The `enum` check takes a `$$` string with one `$` removed.
- Tests: `"$$USD"` against `enum: ["$USD"]` passes; `"$$USD"` against
  `enum: ["$$USD"]` fails.
